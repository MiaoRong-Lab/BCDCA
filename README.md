# BCDCA for PlatEMO

MATLAB implementation of the Bounded Complementary Dual-Channel Algorithm (BCDCA) for constrained multiobjective optimization.

## Contents

- `src/BCDCA/BCDCOA_Revision.m`: PlatEMO entry class for the paper's BCDCA implementation.
- The other MATLAB classes in `src/BCDCA` provide the controller and search, selection, and archive routines used by that entry class. Use `BCDCOA_Revision` to run the paper method.
- `examples/smoke_test_bcdca.m`: a small integration check.

## Requirements

- MATLAB R2018a or later.
- PlatEMO v4.17, installed separately. This is the version used for the integration check.

PlatEMO source is available from [BIMK/PlatEMO](https://github.com/BIMK/PlatEMO). This repository contains the BCDCA implementation and its required project classes; benchmark problems and PlatEMO core classes come from the separate PlatEMO installation.

## Install

Clone this repository and PlatEMO v4.17:

```bash
git clone https://github.com/MiaoRong-Lab/BCDCA.git
git clone --branch v4.17 --depth 1 https://github.com/BIMK/PlatEMO.git
```

In MATLAB, set the two paths and run the integration check:

```matlab
repoRoot = 'path/to/BCDCA';
platemoRoot = 'path/to/PlatEMO';
addpath(genpath(platemoRoot));
addpath(genpath(fullfile(repoRoot, 'src', 'BCDCA')));
addpath(fullfile(repoRoot, 'examples'));
smoke_test_bcdca
```

The check runs MW1, LIRCMOP1, and SDC1 with 30 individuals and a nominal `maxFE` of 300, covering the low-dimensional, high-dimensional soft-constraint, and high-dimensional hard-constraint search modes. It checks installation and execution; the full benchmark campaign and result tables are not generated by this smoke test.

## Run in PlatEMO

For a command-line run with the paper's reported parameters:

```matlab
problem = MW1('N', 100, 'maxFE', 100000);
algorithm = BCDCOA_Revision('parameter', {0.30, 2, 0.25}, 'save', 0);
algorithm.Solve(problem);
```

The parameters are `archiveRatio = 0.30`, `variantCode = 2`, and `rhoMin = 0.25`. Pass them explicitly because the base class default uses a different allocation variant.

For PlatEMO's GUI, add the paths as above, launch `platemo`, choose **Open file** from the algorithm selector, and select `src/BCDCA/BCDCOA_Revision.m`. The paper parameters are listed in the GUI as `archiveRatio = 0.30`, `variantCode = 2`, and `rhoMin = 0.25`.
